# 오쭈다 공식 주소 연결

- `https://ojjuda.com/`과 `https://www.ojjuda.com/`은 현재 운영 중인 `https://ojjuda.kr/` 월드 대문으로 이동합니다.
- `index.html`은 검색 매개변수와 해시를 유지하며 `location.replace`로 이동합니다. JavaScript가 꺼져 있어도 새로고침 메타 태그와 바로가기 링크로 연결합니다.
- 기존 하위 주소는 `404.html`에서 `ojjuda.kr`의 같은 경로로 연결합니다.
- 안내 페이지를 별도로 복제하지 않아 운영 대문 변경이 그대로 적용됩니다.
